## 找熊熊 · 十小关闯关

一个规则推理类益智游戏：棋盘被分成若干彩色区域，**每一行、每一列、每一个色块区域都要有且仅有一只熊熊**。每完成 10 个小关才能解锁下一大关，每过一大关棋盘增加一行一列。

**技术栈**：原生 HTML / CSS / JavaScript · 单文件零依赖 · localStorage

**核心功能**：
- 每小关随机生成全新棋盘，没有固定布局，随时可以「换一盘」
- 冲突实时高亮：涉事格子红框、色块描边，顶部显示冲突数；支持打叉做排除笔记
- 手机短按打叉、原地长按放熊熊，按住滑动可连续打叉（从已有叉起手则连续擦除）；桌面右键等价长按
- 关卡卡片内用 10 段进度条展示小关进度，标注精简为「关卡 / 尺寸 / 完成数」，最佳成绩在选关弹窗查看
- 每小关与整关的最佳用时、最少步数、通关次数保存在本机，已解锁关卡可反复重玩
- 「提示一只」带 60 秒冷却，按钮上直接显示倒计时；切后台自动暂停计时
- 主界面锁定为一屏，棋盘内滑动不会带动页面；模式切换收窄置于棋盘左上，四个功能按钮一行排布，玩法说明用弹窗展示

**在线体验**：<a href="/zhaoxiongxiong/" target="_self">立即试玩找熊熊 →</a>（游戏在本站直接运行，按浏览器后退可返回此页）

**源码**：[GitHub → docs/public/zhaoxiongxiong/index.html](https://github.com/zhoujarvy/zhoujarvy.github.io/blob/main/docs/public/zhaoxiongxiong/index.html)

## 数独游戏

一个基于 Vue 3 + Vite 构建的现代化数独游戏 Web 应用，采用自然绿色配色与温暖金色点缀的精致界面设计。

**技术栈**：Vue 3 · Vite · Canvas API · localStorage

**核心功能**：
- 三档难度（简单 / 中等 / 困难）
- 关联单元格智能高亮（同行、同列、同宫格）
- 基于 Canvas 的手写标记功能，支持多色笔记
- 游戏进度自动保存，随时继续
- 完成谜题后的庆祝动画（彩纸纷飞 + 奖杯弹跳）

**在线体验**：[sudoku.hp110.cn](https://sudoku.hp110.cn/)

**源码**：[GitHub → zhoujarvy/sudoku](https://github.com/zhoujarvy/sudoku)

## 算术练习题生成器

一个轻量实用的算术练习题生成工具，支持 A4 格式精确预览和打印输出，适合家长和老师快速生成练习题。

**技术栈**：Vue 3 · 纯 CSS · 单文件 SPA · Cloudflare Pages

**核心功能**：
- 五种运算类型（加、减、乘、除、加减混合）
- 可自定义数字范围和题目数量
- A4 格式精确预览，支持学生信息栏和演算空间
- 智能分页计算，打印效果与预览一致
- 响应式布局，移动端友好

**在线体验**：[math.hp110.cn](https://math.hp110.cn/)

**源码**：[GitHub → zhoujarvy/math-practice](https://github.com/zhoujarvy/math-practice)
